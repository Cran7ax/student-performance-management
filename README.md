## Overview

A menu-driven C++ application for managing student records and academic performance.

Built as a hands-on project to practise object-oriented programming and understand how linked lists work in practice.

## Features

- Add and manage student records
- Search students by ID
- Update and delete records
- Display student performance
- Identify the class topper
- View performance statistics

## Concepts Used

- Object-Oriented Programming
- Classes, objects and encapsulation
- Singly Linked Lists
- Dynamic memory allocation
- Pointers and traversal

## Build & Run

Requires a C++ compiler with C++17 support.

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic "Student Performance Management System.cpp" -o student_manager
./student_manager
```
